## `Rust/README.md`

# Rust Projects

This folder contains Rust language learning projects and early embedded Rust experiments.

The purpose of this section is to document my progression from basic Rust syntax and Cargo usage into embedded Rust development on the STM32F3Discovery board.

## Folder Structure

| Folder | Description |
|---|---|
| `RustOnly/` 		 | Rust language learning projects that run on a desktop environment |
| `RustWithSTM32F3/` | Embedded Rust projects targeting the STM32F3Discovery board |

## Skills Demonstrated

- Rust project structure
- Cargo usage
- Basic Rust syntax and control flow
- Embedded Rust setup
- `no_std` embedded development
- STM32F3Discovery GPIO control
- ARM Cortex-M project configuration

## Notes

Rust build output is stored in `target/` directories and should not be committed to the repository.
