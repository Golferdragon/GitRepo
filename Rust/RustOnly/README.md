# Rust Language Practice

This folder contains beginner Rust projects used to practice Rust syntax, Cargo project structure, and basic command-line program development.

These projects are part of my self-directed Rust learning path before moving into embedded Rust development.

## Projects

| Project | Description |
|---|---|
| `hello_world/` | Basic Rust program used to verify Rust installation and toolchain setup |
| `hello_cargo/` | Introductory Cargo project used to practice standard Rust project structure |
| `guessing_game/` | Rust guessing game project used to practice user input, control flow, comparison logic, and dependencies |

## Skills Demonstrated

- Rust compiler setup
- Cargo project creation
- Basic Rust syntax
- Variables and mutability
- Standard input handling
- Control flow
- Dependency management
