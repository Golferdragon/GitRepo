# Finished STM32 Projects

This folder contains STM32 projects that are complete enough to be included in the public portfolio.

Projects in this folder are intended to demonstrate embedded development skills in a cleaner, more reviewable form.

## Projects

| Project | Description |
|---|---|
| `TrafficLight_FSM_CPP/` | C++ finite state machine traffic light project for the STM32F3Discovery board |

## Portfolio Standard

Projects in this folder should include:

- A project-level README
- Source code
- STM32CubeIDE project files needed to understand or reopen the project
- Relevant `.ioc` configuration file
- No generated build output folders such as `Debug/` or `Release/`

## Notes

This folder is intended for projects that are ready for review by recruiters, hiring managers, or engineers.
