# STM32 Projects

This folder contains STM32 embedded projects developed using STM32CubeIDE and the STM32F3Discovery development board.

The purpose of this section is to document embedded C/C++ development practice, board bring-up, GPIO control, finite state machines, peripheral work, and ongoing STM32 learning.

## Folder Structure

| Folder | Description |
|---|---|
| `Finished/` 		| Completed or presentation-ready STM32 projects |
| `WorkInProgress/` | Local work-in-progress STM32 projects that may not be included in the public repository |

## Hardware

- STM32F3Discovery board
- STM32F303VCT6 microcontroller
- ST-LINK programmer/debugger

## Tools

- STM32CubeIDE
- STM32CubeMX project configuration
- GCC ARM embedded toolchain
- Git / GitHub

## Skills Demonstrated

- STM32CubeIDE project setup
- GPIO configuration
- Embedded C/C++ development
- Finite state machine design
- Hardware abstraction layer usage
- Debugging and build configuration
- Bare-metal embedded development practice

## Notes

Generated build folders such as `Debug/` and `Release/` should not be committed to the repository.
