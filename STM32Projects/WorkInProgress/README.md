# Work In Progress STM32 Projects

This folder is reserved for STM32 projects that are still under active development.

Work-in-progress projects may be kept locally while they are being developed, tested, and cleaned up. Once a project is complete enough for public review, it can be moved into the `Finished/` folder with a complete project README.

## Current Local Development Areas

| Project | Description |
|---|---|
| `bareMetalSPISTM32F3D/` | Bare-metal SPI development project for the STM32F3Discovery board |

## Public Repository Note

Project contents in this folder may be ignored by Git until they are ready for public review. This keeps the public repository focused on completed or reviewable work.

## Promotion Checklist

Before moving a project from `WorkInProgress/` to `Finished/`, verify that it includes:

- Clean source organization
- Successful build
- Hardware test notes
- Project-level README
- No generated build output folders
- No temporary/debug-only files
- Clear explanation of purpose, tools, hardware, and status
