# Embedded Systems Portfolio

This repository contains selected programming practice, Rust learning projects, and embedded STM32 development projects. It is intended to show my growth and practical experience with C, C++, Rust, embedded systems, microcontroller development, and general software problem solving.

## Repository Structure

| Folder | Description |
|---|---|
| `CodingPractice/` | Small C and C++ practice programs focused on algorithms, data structures, and language fundamentals |
| `Rust/` | Rust language learning projects and early embedded Rust experiments using the STM32F3Discovery board |
| `STM32Projects/` | STM32CubeIDE and bare-metal embedded projects using the STM32F3Discovery board |

## Highlighted Areas

- C and C++ programming practice
- Circular buffer implementation in C
- Rust language learning
- Embedded Rust on STM32F3Discovery
- STM32CubeIDE projects
- GPIO control, finite state machines, and embedded project organization
