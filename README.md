# Embedded Systems Portfolio

This repository contains selected programming practice, Rust learning projects, and embedded STM32 projects as part of my ongoing development as an Embedded Systems Engineer.

## Repository Structure

| Folder | Description |
|---|---|
| CodingPractice | Small C/C++ practice programs focused on algorithms, data structures, and problem solving |
| Rust | Rust language learning and embedded Rust experiments |
| STM32Projects | STM32CubeIDE and bare-metal embedded projects using the STM32F3Discovery board |

## Highlighted Projects

- STM32 Traffic Light FSM in C++
- STM32F3 Rust LED Blinky
- Circular Buffer in C
- Two Sum Hash Map Solution in C++

## Tools & Technologies

C, C++, Rust, STM32CubeIDE, STM32F3Discovery, ARM Cortex-M, Git, embedded systems development
