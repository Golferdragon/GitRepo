# C Practice

This folder contains C language practice programs focused on lower-level programming concepts useful for embedded systems development.

## Current Program

| File | Description |
|---|---|
| `CircularBuffer.c` | Implements and tests a fixed-size circular buffer in C |

## Skills Demonstrated

- C structs
- Fixed-size buffer management
- Head/tail index tracking
- Full and empty state handling
- Wraparound logic using modulo arithmetic
- Basic test-driven verification using console output
