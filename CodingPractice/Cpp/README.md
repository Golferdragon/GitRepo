## `CodingPractice/Cpp/README.md`

# C++ Practice

This folder contains small C++ programs used to practice algorithms, data structures, and problem-solving techniques.

These programs are intentionally simple and self-contained. They are meant to demonstrate continued practice with C++ syntax, standard library usage, pointer-based structures, and algorithmic thinking.

## Programs

| File | Concept |
|---|---|
| `ipStringDedupe.cpp` | String/data cleanup practice |
| `palindromeNumberIntegerSolution.cpp` | Numeric palindrome logic |
| `palindromeNumberSolution.cpp` | Palindrome checking |
| `reverseLinkedList.cpp` | Linked list reversal and pointer manipulation |
| `romanToInteger.cpp` | Roman numeral parsing |
| `romanToIntegerLookupTable.cpp` | Lookup table based parsing |
| `twoSum.cpp` | Brute-force two-sum solution |
| `twoSumHashMapSolution.cpp` | Hash map optimized two-sum solution |

## Skills Demonstrated

- C++ syntax and control flow
- Use of standard library containers
- String parsing
- Hash map lookup
- Pointer manipulation
- Linked list operations
- Algorithmic problem solving

## Build Notes

Each file is intended to be compiled individually.

Example:

```bash
g++ twoSumHashMapSolution.cpp -o twoSumHashMapSolution.exe
